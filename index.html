How Event Delegation Works

Instead of adding separate event handlers to each Task Card, a single click handler is registered on #tasks-container. When you click buttons inside a card, the event bubbles up. JavaScript uses event.target to identify which element triggered the click and runs the corresponding operation.

Attributes vs. Properties

  • Attributes: Defined in the HTML source code (e.g. data-id, class). They represent the initial configuration and are always strings.
  • Properties: Objects in JS memory representing the DOM node (e.g. classList, dataset, id). They are typed and represent the live, editable state.

Pipeline Impact on Actions

  • Reflow + Paint: Caused by structural DOM changes (adding/deleting task cards, resizing window, changing font sizes). Very expensive.
  • Paint Only: Triggered by visual modifications (hover styles, text color edits, backgrounds). Moderately expensive.
  • Composite Only: Occurs on CSS transforms or opacity changes. High-performance; skips layout/painting.
